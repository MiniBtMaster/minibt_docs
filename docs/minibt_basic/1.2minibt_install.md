# **minibt 安装教程**

> **适用版本**：minibt `v1.2.4` &nbsp;|&nbsp; **Python**：3.12+ &nbsp;|&nbsp; **平台**：Windows / macOS / Linux

---

## 一、环境要求

### 1.1 基础环境

minibt 依赖以下基础环境，**强烈建议使用 Python 3.12 及以上版本**（推荐 3.12 - 3.13 系列），可通过以下命令检查当前 Python 版本：

```bash
python --version
```

### 1.2 核心依赖一览

| 依赖 | 用途 | 安装难度 | 备注 |
|------|------|----------|------|
| `numpy` | 科学计算 | 自动安装 | pip 自动拉取 |
| `pandas` | 数据处理 | 自动安装 | v1.2.4 需 pandas 2.x+ |
| `bokeh` | Bokeh 可视化 | 自动安装 | 回测结果图表 |
| `PySide6` | LightChart 桌面图表 | 自动安装 | 实盘 / 回放模式 |
| `optuna` | 贝叶斯参数优化 | 自动安装 | `Bt.optstrategy()` |
| `tqsdk` | 天勤实盘接口 | 自动安装 | 实盘模式必需 |
| `pandas-ta` | Pandas-TA 指标库 | 自动安装 | 可选指标来源 |
| `TA-Lib` | 经典技术指标 | **需手动安装系统依赖** | 性能优于纯 Python 实现 |
| `pyarrow` | 高性能序列化 | 可选 | Parquet 文件支持 |

## 二、安装方式

### （一）通过 pip 安装（推荐）

```bash
pip install minibt
```

该命令会自动拉取 minibt 及其基础依赖（`numpy`、`pandas`、`PySide6`、`bokeh`、`optuna`、`tqsdk` 等），但 `TA-Lib` 需要额外的系统级依赖，详见 [第四节 TALib 安装指南](#talib-install)。

### （二）指定版本 / 镜像加速

```bash
# 安装指定版本
pip install minibt==1.2.4

# 使用清华镜像加速（国内推荐）
pip install minibt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 升级到最新版本
pip install -U minibt
```

### （三）从源码安装（适合开发 / 定制）

```bash
# 克隆仓库
git clone https://github.com/MiniBtMaster/minibt.git
cd minibt

# 可编辑模式安装
pip install -e .
```

或从 PyPI 下载 `.whl` 文件安装：

```bash
python -m pip install minibt-1.2.4-py3-none-any.whl
```

### （四）推荐：使用虚拟环境

为避免依赖冲突，推荐使用虚拟环境：

```bash
# 创建虚拟环境
python -m venv minibt_env

# 激活虚拟环境
# Windows:
minibt_env\Scripts\activate
# Linux / macOS:
source minibt_env/bin/activate

# 在虚拟环境中安装
pip install minibt
```

## 三、验证安装

安装完成后，打开 Python 交互环境（终端执行 `python` 或 `ipython`），依次验证：

```python
# 1. 检查版本号
import minibt
print(minibt.__version__)
# 输出: 1.2.4

# 2. 检查核心模块是否可导入
from minibt import Bt, Strategy, BtIndicator
from minibt import Gui, Config, LocalDatas
from minibt import PandasTa, TaLib, TqTa, TqFunc, TuLip, FinTa, BtInd, Pair, Factors
from minibt import pd, np, options
print("✅ 核心模块全部导入成功")

# 3. 检查可视化后端
from minibt import Gui
print(Gui.Bokeh)      # bokeh
print(Gui.LightChart) # light_chart
print("✅ GUI 后端可用")
```

若输出 `1.2.4`（或对应版本号），且无导入错误，说明安装成功。

## 四、常见问题与解决方案

### 4.1 Python 版本不匹配

**现象**：安装时报错 `No matching distribution found`

**解决**：
```bash
# 检查 Python 版本
python --version

# 如果低于 3.12，需要升级 Python
# 推荐使用 pyenv（跨平台）或从 python.org 下载
```

### 4.2 TA-Lib 安装指南 {: #talib-install }

`TA-Lib` 是 C 语言编写的技术分析库，需要先安装系统级依赖：

#### Windows

```bash
# 方法一：使用预编译的 whl（推荐）
# 从 https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib 下载对应版本
# 或直接：
pip install TA-Lib-0.4.28-cp312-cp312-win_amd64.whl

# 方法二：使用 conda（如果已安装 Anaconda）
conda install -c conda-forge ta-lib
```

#### macOS

```bash
# 使用 Homebrew 安装 TA-Lib 系统库
brew install ta-lib

# 然后安装 Python 包
pip install TA-Lib
```

#### Linux (Ubuntu / Debian)

```bash
# 安装编译依赖
sudo apt-get update
sudo apt-get install -y build-essential wget

# 下载并编译 TA-Lib
wget http://prdownloads.sourceforge.net/ta-lib/ta-lib-0.4.0-src.tar.gz
tar -xzf ta-lib-0.4.0-src.tar.gz
cd ta-lib/
./configure --prefix=/usr
make
sudo make install

# 安装 Python 包
pip install TA-Lib
```

> 💡 **提示**：如果 `TA-Lib` 安装困难，可以暂时跳过。minibt 内置 `PandasTa`、`TqTa`、`BtInd` 等多个纯 Python 指标库，**绝大多数策略不需要 TA-Lib 也能正常运行**。

### 4.3 PySide6 安装问题

**现象**：`light_chart` 模式启动时报 Qt 相关错误

**解决**：
```bash
# 重新安装 PySide6
pip uninstall PySide6 PySide6-Fluent-Widgets -y
pip install PySide6 PySide6-Fluent-Widgets

# 如果仍失败，尝试指定版本
pip install PySide6==6.6.0 PySide6-Fluent-Widgets==1.6.6
```

### 4.4 实盘对接问题

使用 `tqsdk` 时，需正确配置 TQ 账号认证信息：

```python
from minibt import *

bt = Bt(live=True)
bt.addTqapi(tq_auth=tq_auth(
    user_name="你的天勤账号",
    password="你的天勤密码"
))
```

- 若报错"网络连接失败"，检查网络及 TQ 服务器状态
- 若报错"认证失败"，检查账号密码是否正确
- 部分合约需要特定行情权限，请联系天勤客服开通

### 4.5 Cython 加速模块

minibt 内置了 Cython 编译的高性能回测函数（`backtrader_from_signals`），如果系统缺少对应编译版本，框架会自动回退到纯 Python 实现，不影响功能，仅回测速度略有下降。

## 五、平台特定说明

### Windows
- 推荐使用 **PowerShell** 或 **Windows Terminal** 作为命令行工具
- 如果 pip 命令不可用，尝试 `python -m pip install minibt`
- 防火墙可能拦截实盘行情连接，确保 `tqsdk` 网络访问正常

### macOS
- Apple Silicon (M1/M2/M3) 用户：minibt 原生支持 ARM64，无需 Rosetta
- 如遇到 `TA-Lib` 编译问题，优先使用 `brew install ta-lib`

### Linux
- 无头服务器部署时，实盘推荐使用 `bt.run(isplot=False)` 后台模式
- 并行模式（`run_parallel=True`）需要 `multiprocessing` 支持，确保系统未限制进程数
