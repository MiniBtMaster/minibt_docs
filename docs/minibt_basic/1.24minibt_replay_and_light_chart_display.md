# MiniBT 量化交易：策略回放与回测结果图表展示

MiniBT 支持使用 **Lightweight Charts（Qt 版）** 进行回测后的可视化展示，提供两种模式：

1. **K线回放模式** —— 逐根 K 线推进，实时观察策略在历史数据上的决策过程
2. **回测结果图表展示模式** —— 一次性加载全部数据，用于快速浏览和检查回测结果

两种模式均基于 `lightweight-charts` + `PySide6` + `FluentUI` 构建，比传统 Bokeh 图表更流畅、交互更自然。

---

## K线回放模式

在回放模式下，框架会先完成完整回测，然后以可视化方式逐根 K 线重新播放走势和交易信号。

### 基本用法

```python
from minibt import *

class MyStrategy(Strategy):
    def __init__(self):
        self.data = self.get_kline(LocalDatas.v2601_300, height=300)
        self.ma = self.data.close.sma(10)

    def next(self):
        if not self.data.position:
            if self.data.close > self.ma:
                self.data.buy(stop=BtStop.Trailing)

if __name__ == "__main__":
    bt = Bt(replay=True)        # 启用回放模式
    bt.run(
        isplot=True,            # 启用图表
        gui="light_chart",      # 使用 lightweight_charts（Qt）
        period_milliseconds=500 # 回放速度：500 毫秒/根
    )
```

### 界面说明

| 控件 | 功能 |
|------|------|
| 暂停/继续按钮 | 控制回放进度，初始为暂停状态，点击后开始播放 |
| 速度滑块 | 调节回放速度（毫秒/根），实时生效 |
| 进度条 | 显示当前回放进度和 K 线索引 |
| 合约列表 | 左侧显示当前策略下的所有合约，双击切换 |
| 交易标记 | K 线上自动标记买入/卖出信号 |

## 回测结果图表展示模式

如果只是想快速查看回测完成后的 K 线图、指标和交易信号（不需要逐根回放），可以使用 **纯图表展示模式**。

### 基本用法

```python
if __name__ == "__main__":
    bt = Bt(replay=False)       # 常规回测模式（非回放）
    bt.run(
        isplot=True,            # 回测结束后展示图表
        gui="light_chart",      # 使用 lightweight_charts 展示
    )
```

### 与回放模式的区别

| 特性 | 回放模式 (`replay=True`) | 图表展示模式 (`gui="light_chart"`) |
|------|--------------------------|-------------------------------------|
| 运行方式 | 先回测，再逐 K 回放 | 回测后直接展示 |
| 数据加载 | 初始加载部分 K 线，后续逐根追加 | 一次性加载全部 K 线 |
| 控制栏 | 显示暂停/继续/速度调节 | **隐藏** |
| 适用场景 | 观察策略决策过程、演示 | 快速检查回测结果 |

## 通用参数说明

### `gui` 参数

在 `Bt.run()` 中通过 `gui` 参数控制图表引擎：

```python
# 使用 lightweight_charts（Qt 界面）
bt.run(isplot=True, gui="light_chart")

# 使用传统 Bokeh 图表（默认）
bt.run(isplot=True, gui="bokeh")
```

### `initial_candles` 与 `min_start_length`

- 回放/展示模式默认加载的初始 K 线数，优先读取策略的 **`min_start_length`** 参数
- 若策略未设置或值过小，则自动兜底为 **100** 根，避免预热不足导致指标显示异常

```python
class MyStrategy(Strategy):
    params = dict(min_start_length=200)  # 预热 200 根 K 线
```

### `period_milliseconds`

仅对回放模式有效，控制每根 K 线的播放间隔：

| 取值 | 效果 |
|------|------|
| `1000` | 慢速回放（1 秒/根） |
| `500`  | 中速回放 |
| `200`  | 快速回放 |
| `0`    | 最快速度 |

## 多策略与多合约

两种方式均天然支持多策略、多合约：

```python
bt = Bt(replay=True)
bt.addstrategy(StrategyA, StrategyB)
bt.run(gui="light_chart")
```

左侧合约列表会列出所有策略下的全部合约，双击即可切换查看。

---

## 与 Bokeh 图表的对比

| 对比项 | Bokeh | Lightweight Charts (Qt) |
|--------|-------|-------------------------|
| 渲染引擎 | HTML/浏览器 | Qt + JS 图表引擎 |
| 交互体验 | 浏览器内操作 | 原生桌面窗口 |
| 启动速度 | 需生成 HTML | 直接弹出窗口 |
| 权益曲线 | 主图下方独立子图 | 当前版本仅展示 K 线与指标 |
| 主题 | 支持黑色/白色 | 支持明暗主题切换 |

> **提示**：若需要查看权益变化图，当前版本请继续使用 `gui="bokeh"`。后续版本将在 light_chart 中补充独立的回测结果面板。

## 完整示例

```python
from minibt import *

class DemoStrategy(Strategy):
    params = dict(symbol="DCE.v2601")

    def __init__(self):
        self.data = self.get_kline(self.params.symbol, 60, 1000)
        self.gc = self.data.tradingview.G_Channels()
        self.macd = self.data.close.macd()

    def next(self):
        if not self.data.position:
            if self.gc.long_signal.new:
                self.data.buy(stop=BtStop.SegmentationTracking)
            elif self.gc.short_signal.new:
                self.data.sell(stop=BtStop.SegmentationTracking)

if __name__ == "__main__":
    # 方式一：K线回放
    bt = Bt(replay=True)
    bt.run(gui="light_chart", period_milliseconds=500)

    # 方式二：回测后图表展示
    # bt = Bt(replay=False)
    # bt.run(isplot=True, gui="light_chart")
```
