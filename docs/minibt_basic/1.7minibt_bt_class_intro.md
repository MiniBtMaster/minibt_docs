# **MiniBT 量化交易：Bt 类介绍**

## 概述

&emsp;&emsp;Bt 类是 MiniBT 量化回测与实盘框架的核心引擎，类似于 backtrader 中的 Cerebro。它负责协调整个回测/实盘流程，包括数据加载、策略管理、参数优化、执行引擎和结果分析。

---

## 一、Bt 类初始化参数

```python
Bt(auto=True, live=False, replay=False, **kwargs)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `auto` | `bool` | `True` | 是否自动扫描全局变量中的 DataFrame 数据和 TqApi 实例。调试时开启方便快速上手，生产环境建议关闭后手动添加资源 |
| `live` | `bool` | `False` | 是否启用实盘模式。`True` 时连接实盘/模拟盘执行实时交易，`False` 时基于历史数据执行回测 |
| `replay` | `bool` | `False` | 是否启用 K 线回放模式。`True` 时逐根 K 线推进回测（模拟实时过程），`False` 时一次性完成全部回测 |
| `**kwargs` | `dict` | — | 额外配置。`quick_live`：快速实盘配置字典，含 `live` 键控制是否进入实盘 |

### 三种运行模式总览

| 模式 | 初始化 | 适用场景 |
|------|--------|---------|
| **回测模式** | `Bt()` 或 `Bt(auto=True)` | 基于历史数据评估策略表现，一次性计算结果 |
| **回放模式** | `Bt(replay=True)` | 逐 K 线推进回测，可搭配 LightChart / live_plot 图形化回放 |
| **实盘模式** | `Bt(live=True)` | 对接天勤 API，执行实时/模拟交易 |

## 二、核心方法详解

### 2.1 数据管理

#### `adddata(*args, **kwargs) -> Bt`

添加回测数据（pandas.DataFrame），支持多个 DataFrame 同时添加。

```python
bt = Bt(auto=False)
bt.adddata(df1, df2)  # 支持链式调用
```

- 数据必须包含字段：`datetime`, `open`, `high`, `low`, `close`, `volume`
- `auto=True` 时框架会自动扫描全局变量中的合规 DataFrame，无需手动调用

#### `addTqapi(tq_auth=None, tq_account=None, api=None) -> Bt`

连接天勤实盘/模拟盘 API，实盘模式必须调用。

| 参数 | 类型 | 说明 |
|------|------|------|
| `tq_auth` | `tq_auth` | 天勤用户认证（`tq_auth(user_name="账号", password="密码")`） |
| `tq_account` | `tq_account` | 实盘账户信息，不传则使用模拟盘 |
| `api` | `TqApi` | 已初始化的天勤 API 实例（与 tq_auth 二选一） |

```python
bt = Bt(live=True)
bt.addTqapi(tq_auth=tq_auth(
    user_name="天勤账号", password="天勤密码"
))
```

### 2.2 策略管理

#### `addstrategy(*args, **kwargs) -> Bt`

添加策略，支持多种输入方式。

| 输入类型 | 示例 | 说明 |
|---------|------|------|
| **Strategy 类** | `addstrategy(MyStrategy)` | 直接传入策略类 |
| **模块名字符串** | `addstrategy('cci')` | 从当前目录 `cci.py` 自动发现 Strategy 子类 |
| **多个文件** | `addstrategy('cci', 'cmo')` | 同时加载多个文件中的策略 |
| **显式 .py 路径** | `addstrategy('./my_strategies/cci.py')` | 指定完整路径 |
| **目录路径** | `addstrategy('.')` | 扫描目录下所有 `*.py` 文件（排除 `__init__.py`） |
| **Python 包路径** | `addstrategy('strategies.cci')` | 使用标准模块导入语法 |
| **混合传入** | `addstrategy(MyStrategy, 'cmo')` | 类 + 字符串混用 |
| **带参数** | `addstrategy(MyStrategy, period=14)` | kwargs 通过 setattr 注入策略类属性 |

```python
# 回测模式
Bt().addstrategy(CCIStrategy).run()

# 从文件加载
Bt().addstrategy('cci', 'cmo').run(gui=Gui.LightChart)

# 实盘模式 + 文件加载
bt = Bt(live=True)
bt.addstrategy('cci', 'cmo')
bt.addTqapi(tq_auth=tq_auth(user_name="账号", password="密码"))
bt.run()
```

### 2.3 参数优化

#### `optstrategy(target, weights, opconfig, op_method, show_bar, skip, **kwargs) -> Bt`

配置策略参数优化（设置后需调用 `run()` 才会执行优化）。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `target` | `str` / `list[str]` | `'profit_ratio'` | 优化目标，支持：`profit_ratio`（盈利比）、`sharpe`（夏普率）、`max_drawdown`（最大回撤）、`win_rate`（胜率）、`cagr`（年化收益率）等 |
| `weights` | `float` / `tuple` | `1.0` | 目标权重，正数最大化、负数最小化。多目标时传入元组 |
| `opconfig` | `OpConfig` / `OptunaConfig` / `dict` | `{}` | 优化算法配置参数 |
| `op_method` | `'ga'` / `'optuna'` | `'optuna'` | 优化算法：遗传算法（GA）或贝叶斯优化（Optuna） |
| `show_bar` | `bool` | `True` | 是否显示优化进度条 |
| `skip` | `bool` | `False` | 是否跳过优化 |
| `**kwargs` | — | — | 待优化参数。支持 `range(1,10)`、`(10,30,2)`、`[3,5,8,13]` 等格式 |

```python
bt = Bt(replay=False)
bt.addstrategy(MyStrategy)
bt.optstrategy(
    target='profit_ratio',          # 优化目标：盈利比
    op_method='optuna',             # 使用贝叶斯优化
    period=(5, 30, 1),              # period 在 5-30 范围内搜索，步长 1
    upper=(80, 120, 5),             # upper 在 80-120 范围内搜索，步长 5
    lower=[-120, -100, -80]         # lower 从固定列表中选择
)
bt.run()  # 执行优化
```

### 2.4 执行方法

#### `run(isplot=True, isreport=False, **kwargs) -> Bt`

**最核心的统一入口**，根据初始化配置自动选择运行模式。

##### 基本参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `isplot` | `bool` | `True` | 回测模式是否生成可视化图表（Bokeh/LightChart）<br>实盘模式：`True`=图表模式，`False`=后台/并行 |
| `isreport` | `bool` | `False` | 是否生成 QuantStats 量化分析报告（HTML 格式） |

##### 回放模式参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `replay` | `bool` | `False` | 是否启用回放（可覆盖构造函数中的 replay 设置） |
| `gui` | `str` | `'live_plot'` | 回放 GUI 类型。`'live_plot'`：文件 IPC 模式独立画图进程；`'light_chart'`：Qt 内嵌 LightChart 图表 |
| `initial_candles` | `int` | `300` | light_chart 模式初始加载 K 线数 |
| `replay_speed_ms` | `int` | `500` | light_chart 模式回放速度（毫秒/根 K 线） |
| `update_length` | `int` | `10` | 回放和实盘时每次更新的数据长度 |

##### 可视化图表参数（传递至 bokeh_plot）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `trade_signal` | `bool` | `True` | 是否显示交易信号标记（开仓/平仓箭头） |
| `black_style` | `bool` | `False` | 是否使用黑色主题 |
| `plot_width` | `int` | `None` | 图表宽度（像素，默认自适应） |
| `plot_cwd` | `str` | `""` | 图表文件存储目录 |
| `plot_name` | `str` | `""` | 图表文件名称 |
| `open_browser` | `bool` | `False` | 是否在浏览器中自动打开 |
| `save_plot` | `bool` | `True` | 是否保存 HTML 文件 |
| `gui` | `str` | `'bokeh'` | 图表类型。`'bokeh'`：Bokeh 交互图表；`'light_chart'`：Qt LightChart（一次性展示，非回放） |

##### 分析报告参数（传递至 qs_reports）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `report_cwd` | `str` | `""` | 报告存储目录 |
| `report_name` | `str` | `""` | 报告文件名称 |
| `report_height` | `int` | `800` | 报告页面高度（像素） |
| `show` | `bool` | `True` | 生成后是否立即显示 |
| `keep_temp` | `bool` | `True` | 是否保留临时文件 |

##### 统一路径/名称（同时影响图表和报告）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `cwd` | `str` | `""` | 图表和报告的统一存储目录 |
| `name` | `str` | `""` | 图表和报告的统一文件名称 |

##### 实盘/并行参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `period_milliseconds` | `int` | `1000` | 实盘 K 线轮询间隔（毫秒） |
| `run_parallel` | `bool` | `False` | 实盘模式下是否启动多进程并行（每策略独立进程 + 独立 TqApi） |
| `print_account` | `bool` | `False` | 回测完成后是否打印账户详情 |

- `model`：多策略并行回测的并行库（默认 `'joblib'`，也支持 `'dask'`、`'sklearn'`、`'multiprocessing'`）

## 三、运行模式与典型示例

### 3.1 回测模式

```python
# 最简回测
Bt().run()

# 完整回测：LightChart GUI + 报告
Bt().run(gui=Gui.LightChart, isreport=True)

# 多策略回测
Bt().addstrategy(CCIStrategy, CMOStrategy).run(gui=Gui.LightChart)

# 黑色主题图表
Bt().run(black_style=True, plot_name="my_backtest")
```

### 3.2 回放模式

```python
# 控制台回放
Bt(replay=True).run()

# LightChart 图形化逐K线回放（最直观）
Bt(replay=True).run(gui=Gui.LightChart)

# 自定义回放速度
Bt(replay=True).run(gui=Gui.LightChart,
                     initial_candles=500,
                     replay_speed_ms=200)
```

### 3.3 实盘模式（三种子模式）

```python
bt = Bt(live=True)
bt.addstrategy(MyStrategy)
bt.addTqapi(tq_auth=tq_auth(user_name="账号", password="密码"))

# 模式一：图表模式 — GUI 实时看盘
bt.run()

# 模式二：后台串行 — 无 GUI，单进程，低资源占用
bt.run(isplot=False)

# 模式三：并行模式 — 每策略独立进程 + 独立 TqApi，进程级隔离
bt.run(isplot=False, run_parallel=True)
```

## 四、结果可视化与分析

### 4.1 Bokeh 交互图表

```python
bt.bokeh_plot(
    trade_signal=True,       # 显示交易信号标记
    black_style=False,       # 白色主题
    open_browser=False,      # 不在浏览器打开（Jupyter 中建议 False）
    plot_width=1200,         # 图表宽度
    plot_name="my_plot",     # 文件名
    save_plot=True           # 保存 HTML
)
```

### 4.2 QuantStats 报告

```python
# 完整 HTML 报告（推荐）
bt.qs_reports(
    report_name="strategy_report",
    show=True
)

# 内置多种报告级别
bt.qs_metrics()     # 仅数值指标，无图表
bt.qs_plots()       # 仅图表，无指标
bt.qs_basic()       # 基础报告：核心指标 + 关键图表
bt.qs_full()        # 完整报告：所有指标 + 图表 + 分析结论
bt.qs_html(         # 生成 HTML 文件（支持自定义标题和模板）
    title='我的策略报告',
    output='reports/my_tearsheet.html'
)
bt.qs_iDisplay()    # Jupyter Notebook 中交互式显示
bt.qs_iHTML()       # Jupyter 中显示 HTML 报告
```

### 4.3 获取回测数据与统计对象

```python
# 获取原始回测数据（DataFrame 格式）
results = bt.get_results()           # 所有策略
results = bt.get_results(select=0)   # 第0个策略

# 获取 QuantStats Stats 对象（可调任意指标方法）
stats = bt.qs_stats(select=0)
print(stats.sharpe())         # 夏普率
print(stats.max_drawdown())   # 最大回撤
print(stats.win_rate())       # 胜率
print(stats.cagr())           # 年化收益率

# 获取 QuantStats QSPlots 对象（可调任意绘图方法）
plots = bt.qs_plot(select=0)
plots.returns()               # 收益率曲线
plots.drawdown()              # 回撤曲线
plots.monthly_heatmap()       # 月度收益热力图
```

## 五、综合使用流程

```python
if __name__ == "__main__":
    # 1. 初始化（回测模式）
    bt = Bt(replay=False)

    # 2. 添加策略（支持类、文件路径、目录等多种方式）
    bt.addstrategy(CCIStrategy, CMOStrategy)

    # 3.（可选）参数优化
    # bt.optstrategy(target='sharpe', op_method='optuna',
    #                CCI_PERIOD=(5, 30, 1))

    # 4. 执行回测
    bt.run(
        gui=Gui.LightChart,     # LightChart 图表展示
        isreport=True,          # 同时生成 QuantStats 报告
        report_name="backtest_report",
        black_style=True        # 暗色主题
    )

    # 5. 分析结果
    bt.bokeh_plot(save_plot=True)       # 保存 Bokeh 图表
    stats = bt.qs_stats(select=0)       # 获取统计对象
    print(f"夏普率: {stats.sharpe():.2f}")
    print(f"最大回撤: {stats.max_drawdown():.2%}")
```

## 六、特性亮点

1. **轻量级设计**：相比 backtrader，minibt 更加轻量简洁，上手快
2. **三种运行模式**：回测 → 回放 → 实盘，代码几乎无需修改即可切换
3. **多策略并行**：原生支持多策略并行回测（joblib/dask/sklearn/multiprocessing）
4. **实盘多模式**：图表模式 / 后台串行 / 多进程并行，覆盖本地调试到服务器部署
5. **策略文件加载**：支持类、模块名、文件路径、目录、包路径等多种加载方式
6. **灵活的参数优化**：GA 遗传算法 + Optuna 贝叶斯优化，支持多目标
7. **丰富的可视化**：Bokeh 交互图表 + LightChart Qt 实时看盘 + QuantStats 专业报告
8. **强化学习支持**：内置 RL 策略回测框架

---

## 七、与 backtrader 的对比

| 特性 | MiniBT Bt | backtrader Cerebro |
|------|----------|-------------------|
| 设计理念 | 轻量级、易用 | 功能全面、复杂 |
| 运行模式 | 回测 / 回放 / 实盘无缝切换 | 主要面向回测 |
| 并行支持 | 原生多策略并行（4种后端） | 有限并行支持 |
| 实盘集成 | 深度集成天勤 API | 需额外扩展 |
| 参数优化 | GA + Optuna 多目标 | 基础优化功能 |
| 策略文件加载 | 字符串路径自动发现 | 不支持 |
| 可视化 | Bokeh + LightChart + QuantStats | 基础 matplotlib |
| 学习曲线 | 较低 | 较高 |

&emsp;&emsp;Bt 类作为 MiniBT 框架的核心，提供了一个现代化、功能丰富的量化回测和实盘交易平台，特别适合需要快速迭代策略、进行参数优化和实盘交易的开发者使用。
