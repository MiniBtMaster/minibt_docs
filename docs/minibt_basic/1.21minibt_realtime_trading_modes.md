# MiniBT 量化交易：三种实盘运行模式介绍

从 `v1.2.4` 开始，MiniBT 支持三种实盘运行模式，满足不同部署场景的需求：

## 三种模式对比

| 模式 | 调用方式 | 适用场景 | 进程数 | TqApi 连接数 |
|------|---------|---------|--------|-------------|
| **图表模式** | `bt.run(isplot=True)` | 实时看盘，需要可视化 | 1 | 1 |
| **后台串行** | `bt.run(isplot=False)` | 单进程多策略，共享一个 TqApi | 1 | 1 |
| **并行模式** | `bt.run(isplot=False, run_parallel=True)` | 每个策略独立进程+独立 TqApi | N（策略数） | N |

---

## 1. 图表模式

启动 **Qt GUI + lightweight-charts** 实时图表窗口，支持多合约切换、技术指标显示、交易信号标记、账户面板等完整功能。

```python
from minibt import *

bt = Bt(live=True)
bt.addstrategy(MyStrategy)
bt.addTqapi(tq_auth=tq_auth(user_name="天勤账号", password="天勤密码"))

# 启动图表窗口
bt.run(isplot=True, period_milliseconds=1000)
```

**特点：**

- 可视化 K 线、指标、持仓信号
- 实时账户盈亏面板
- 双击合约列表切换
- 适合本地盯盘、策略调试

---

## 2. 后台串行模式

不启动任何 GUI，所有策略在同一个进程内串行执行，共享同一个 `TqApi` 连接。

```python
bt.run(isplot=False, period_milliseconds=1000)
```

**启动输出示例：**

```
==================================================
[后台实盘模式] 已启动，不显示图表
策略数量: 3
==================================================
```

**特点：**

- 无窗口、无图形，资源占用低
- 单进程内循环调用所有策略的 `_execute_live_trading()`
- 所有策略共享行情连接，适合策略数量不多、相互独立的场景
- `Ctrl+C` 优雅退出

---

## 3. 并行模式

每个策略启动一个**独立进程**，各自创建独立的 `Bt` 实例和独立的 `TqApi` 连接，真正实现进程级隔离。

```python
bt.run(isplot=False, run_parallel=True, period_milliseconds=1000)
```

**启动输出示例：**

```
==================================================
[并行模式] 启动 3 个独立进程
  [0] CCIStrategy
  [1] CMOStrategy
  [2] HullStrategy
==================================================
[并行模式] CCIStrategy 启动成功 (PID=8068)
[并行模式] CMOStrategy 启动成功 (PID=27612)
[并行模式] HullStrategy 启动成功 (PID=7256)
==================================================
[后台实盘模式] 已启动，不显示图表
策略数量: 1
...
```

**特点：**

- **进程隔离**：任一策略崩溃不会影响其他策略
- **独立连接**：每个策略独占一个天勤 API 连接，避免锁竞争
- **资源利用**：可充分利用多核 CPU
- 父进程仅负责 fork + 等待，不执行策略逻辑
- `Ctrl+C` 统一终止所有子进程

---

## 完整示例

```python
# run_multi.py
from minibt import *
import importlib

CCIStrategy = importlib.import_module('cci').CCIStrategy
CMOStrategy = importlib.import_module('cmo').CMOStrategy
HullStrategy = importlib.import_module('hull').HullStrategy

if __name__ == "__main__":
    bt = Bt(live=True)
    bt.addstrategy(CCIStrategy, CMOStrategy, HullStrategy)
    bt.addTqapi(tq_auth=tq_auth(
        user_name="天勤账号", password="天勤密码"
    ))

    # 三种模式任选其一
    # bt.run(isplot=True)                              # 图表模式
    # bt.run(isplot=False)                             # 后台串行
    bt.run(isplot=False, run_parallel=True)            # 并行模式
```

---

## 注意事项

1. **Windows 兼容性**：并行模式使用 `multiprocessing.Process`，Windows 默认 `spawn` 方式，已通过独立 `Bt` + `TqApi` 初始化避免 fork 导致的资源冲突。

2. **认证信息**：并行模式下，父进程的 `addTqapi()` 必须传入 `tq_auth`（和可选的 `tq_account`），认证参数会在 fork 时传递给子进程，由子进程独立创建 `TqApi` 实例。

3. **日志**：并行模式下，各策略的输出会分散在各自进程的标准输出中。如需集中收集，建议配置策略内部的日志系统（如 `strategy.logger`）写入文件或远程服务。
