# minibt 停止类（Stop）：灵活高效的多空止损止盈管理方案

minibt 框架中的 `Stop` 类是量化交易策略中止损/止盈逻辑的核心抽象层，专为期货、股票等多空交易场景设计，提供标准化、可扩展的停止价管理机制，让开发者无需关注底层框架逻辑，只需聚焦策略业务规则的实现。

## 核心设计理念

`Stop` 类以「极简接口 + 全量能力」为核心，通过封装 KLine 数据访问、价格序列管理、多空逻辑分离等底层能力，将自定义止损止盈策略的开发简化为「初始化指标 + 实现多空逻辑」两步，大幅降低量化策略的开发成本和维护难度。

## 核心能力特性

### 1. 初始化阶段：灵活的指标预处理

子类实现 `__init__` 方法时，可完成任意技术指标的前置计算（如ATR、标准差、smoothrng等），计算结果可绑定为实例属性（如 `self._atr`），供后续 `long/short` 方法直接复用，避免重复计算，提升策略执行效率。

- 典型场景：初始化时计算14周期ATR指标，后续多空止损逻辑直接调用该指标值。

### 2. 全量KLine对象访问：一站式数据调用

停止类实例可无限制访问 `KLine` 对象的所有属性和方法，同时框架提供便捷属性映射，无需冗长的调用路径：

- 直接调用：`self.kline.atr()`、`self.kline.position`、`self.kline.open_price` 等
- 便捷映射：`self.open/self.high/self.low/self.close/self.volume` 直接关联KLine对应序列

### 3. 标准化接口：极简的自定义开发范式

自定义停止策略仅需重写三个核心方法，即可实现完整的止损止盈逻辑：

- `__init__`：初始化策略参数、前置计算技术指标
- `long`：实现多头停止价/目标价计算逻辑
- `short`：实现空头停止价/目标价计算逻辑

停止价/目标价的赋值采用统一范式，框架自动维护价格序列（支持 `[-1]` 最新价、`[-2]` 前一价等索引访问）：
```python
self.stop_price.new = 计算后的止损价
self.target_price.new = 计算后的止盈价
```

### 4. 多头停止价管理：精细化多仓风控

`long()` 方法专用于多头持仓的止损（stop_price）和止盈（target_price）设置，框架内置触发逻辑：

- 触发条件：最新收盘价 ≤ 止损价 **或** 最新收盘价 ≥ 止盈价
- 自动执行：满足条件时自动调用 `self.kline.set_target_size()` 完成平仓操作，无需手动处理。

### 5. 空头停止价管理：对称化空仓风控

`short()` 方法专用于空头持仓的止损（stop_price）和止盈（target_price）设置，与多头逻辑完全对称，适配完整的多空交易场景：

- 触发条件：最新收盘价 ≥ 止损价 **或** 最新收盘价 ≤ 止盈价
- 自动执行：满足条件时自动调用 `self.kline.set_target_size()` 完成平仓操作。

## 接口设计优化亮点
### 1. 统一的只读属性封装

框架封装了交易场景的核心属性，采用只读属性方式提供统一访问入口，避免属性篡改，提升代码健壮性：
| 属性名            | 说明             |
| ----------------- | ---------------- |
| `price_tick`      | 合约最小变动单位 |
| `volume_multiple` | 合约乘数         |
| `datetime`        | 时间序列         |
| `stop_price`      | 止损价序列       |
| `target_price`    | 止盈价序列       |

### 2. 抽象化核心方法

`long()`/`short()` 作为抽象接口，子类只需实现业务逻辑，无需关注框架层的价格更新、序列维护、触发判断等底层逻辑，降低开发心智负担。

### 3. 自动持仓方向识别

内置 `update()` 方法自动识别当前持仓方向（多头/空头），并调用对应 `long/short` 方法，开发者无需手动判断持仓状态，简化代码逻辑。

## 快速上手示例：ATR动态止损策略
#### 以下示例展示如何基于 `Stop` 类快速实现一个经典的ATR动态止损止盈策略：
```python
class ATRDynamicStop(Stop):
    """基于ATR的动态止损止盈策略"""

    def __init__(self, atr_length: int = 14, atr_mult: float = 1.0):
        # 初始化参数
        self.atr_length = atr_length
        self.atr_mult = atr_mult
        # 前置计算ATR指标（核心能力1）
        self._atr = self.kline.atr(self.atr_length)  # 全量KLine访问（核心能力2）

    def long(self):
        """多头ATR动态止损止盈（核心能力3+4）"""
        # 计算多头止损价：最新最低价 - ATR*乘数
        if np.isnan(self.stop_price[-2]):
            stop_price = self.low[-1] - self.atr_mult * self._atr[-1]
        else:
            stop_price = self.stop_price[-2]
        # 计算多头止盈价：开仓价 + 2倍止损空间
        if np.isnan(self.target_price[-2]):
            target_price = self.kline.open_price + \
                (self.kline.open_price - stop_price) * 2
        else:
            target_price = self.target_price[-2]
        # 赋值停止价/目标价
        self.stop_price.new = stop_price
        self.target_price.new = target_price

    def short(self):
        """空头ATR动态止损止盈（核心能力3+5）"""
        # 计算空头止损价：最新最高价 + ATR*乘数
        if np.isnan(self.stop_price[-2]):
            stop_price = self.high[-1] + self.atr_mult * self._atr[-1]
        else:
            stop_price = self.stop_price[-2]
        # 计算空头止盈价：开仓价 - 2倍止损空间
        if np.isnan(self.target_price[-2]):
            target_price = self.kline.open_price - \
                (stop_price - self.kline.open_price) * 2
        else:
            target_price = self.target_price[-2]
        # 赋值停止价/目标价
        self.stop_price.new = stop_price
        self.target_price.new = target_price


class owen(Strategy):

                    take_time=True, islogorder=False)
    params = dict(symbol="v2601_300",)

    def __init__(self):
        self.min_start_length = 300
        self.data = self.get_kline(

        self.ma5 = self.data.close.sma(5)
        self.ma10 = self.data.close.sma(10)
        self.long_signal = self.ma5.cross_up(self.ma10)
        self.short_signal = self.ma5.cross_down(self.ma10)

    def next(self):
        if not self.data.position: 
            if self.long_signal.new:
                self.data.buy(exectype=OrderType.Market,
                              stop=ATRDynamicStop)
            elif self.short_signal.new:
                self.data.sell(exectype=OrderType.Market,
                               stop=ATRDynamicStop)

    Bt().run()
```

## 核心优势总结

1. **开发效率高**：标准化接口让自定义止损止盈策略的开发仅需聚焦核心逻辑，无需重复造轮子；
2. **扩展性强**：支持任意技术指标的前置计算，可适配均线、布林带、波动率等各类止损策略；
3. **多空适配完整**：多头/空头逻辑分离且对称，完美支持多空双向交易场景；
4. **底层能力完备**：封装KLine访问、价格序列管理、自动平仓触发等底层能力，降低出错概率；
5. **易用性佳**：便捷的属性映射和统一的赋值方式，让代码更简洁、易读、易维护。

无论是简单的固定点位止损，还是复杂的动态分段止损策略，基于 `Stop` 类都能快速实现，是minibt量化框架中连接策略逻辑与交易执行的核心桥梁。
