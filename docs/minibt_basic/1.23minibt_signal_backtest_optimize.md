# MiniBT 量化交易：signal_backtest 指标信号参数优化详解

本文详细介绍 `IndFrame.signal_backtest` 的参数优化功能。通过 `OptimizeConfig` dataclass，可以统一管理网格搜索（Grid Search）与 Optuna 贝叶斯优化的全部配置，实现单目标、多目标、带权重等多种优化场景。

---

## 一、OptimizeConfig 参数配置类

`OptimizeConfig` 是一个基于 `dataclass` 的配置类，用于集中定义参数优化的所有设置。

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `params` | `dict` | **必需** | 待优化参数与取值范围。例如 `{'length1': (5, 30, 2), 'length2': (30, 60, 2)}` |
| `target` | `str` / `list[str]` | `'sharpe'` | 优化目标指标名，支持所有 `_calc_qs_metrics` 计算的指标 |
| `method` | `str` | `'optuna'` | 优化方法：`'grid'`（网格搜索）或 `'optuna'`（贝叶斯优化） |
| `weights` | `float` / `tuple[float]` / `None` | `None` | 优化目标权重。`>0` 最大化，`<0` 最小化；不设置则默认等权重 `1.0` |
| `config` | `dict` / `None` | `None` | 优化器配置，如 `{'n_trials': 100, 'sampler': 'TPESampler'}` |
| `n_jobs` | `int` | `1` | 并行线程数，`-1` 使用全部 CPU 核心 |
| `output_dir` | `str` | `''` | CSV 结果导出目录，默认不导出 |

### `params` 格式说明与类型推断

| 格式 | 示例 | 推断类型 | 说明 |
|------|------|----------|------|
| `(low, high)` | `(5, 30)` | **int** | 两个整数，自动推断为整数搜索区间（Optuna 使用 `suggest_int`） |
| `(low, high, step)` | `(5, 30, 2)` | **int** | 三个数均为整数，step 为整数步长 |
| `(low, high, step)` | `(1.5, 3.0, 0.5)` | **float** | 含小数时推断为 float（Optuna 使用 `suggest_float`） |
| `['a', 'b', 'c']` | `['fast', 'slow']` | **cat** | 列表（含字符串）→ 类别型（`suggest_categorical`） |

> **类型推断规则**：`low`、`high` 及 `step`（如有）全部为整数，或等价于整数的浮点数（如 `5.0`）时，自动推断为 `int`；否则为 `float`。因此均线周期等参数使用 `(5, 30)` 即可正确搜索整数，不会出现小数。

### `config` 支持参数

| 参数 | 类型 | 默认值 | 适用方法 | 说明 |
|------|------|--------|----------|------|
| `n_trials` | `int` | `100` | optuna | 贝叶斯优化试验次数 |
| `sampler` | `str` | `NSGAIISampler` | optuna | 采样器名称，可选 `BaseSampler`、`GridSampler`、`RandomSampler`、`TPESampler`、`CmaEsSampler`、`PartialFixedSampler`、`NSGAIISampler`（多目标推荐，默认）、`NSGAIIISampler`、`MOTPESampler`、`QMCSampler`、`BruteForceSampler`、`IntersectionSearchSpace`、`intersection_search_space` |
| `pruner` | `str` / `None` | `HyperbandPruner` | optuna | 剪枝器名称，可选 `BasePruner`、`MedianPruner`、`NopPruner`、`PatientPruner`、`PercentilePruner`、`SuccessiveHalvingPruner`、`HyperbandPruner`（默认）、`ThresholdPruner`；设为 `None` 关闭剪枝 |
| `verbose` | `bool` | `True` | optuna | 是否输出 Optuna 详细日志 |
| `show_progress_bar` | `bool` | `True` | optuna | 是否显示优化进度条 |
| `n_jobs` | `int` | `1` | 通用 | 并行线程数；当 `OptimizeConfig.n_jobs` 为 `1` 时，优先取此值 |

### 使用方式

将 `OptimizeConfig` 实例直接传入 `signal_backtest` 的 `optimize` 参数即可：

```python
from minibt.indicators._core import OptimizeConfig

config = OptimizeConfig(
    params={'length1': (5, 30, 2), 'length2': (30, 60, 2)},
    target='sharpe',
    method='grid',
    n_jobs=4,
    output_dir='./results',
)
result = ind.signal_backtest(optimize=config)
result.pprint()
```

> **兼容说明**：旧版 `optimize=True` 配合 `optimize_params`、`optimize_target` 等 `**kwargs` 的方式仍然保留，但推荐使用 `OptimizeConfig` 进行统一管理。

## 三、11 个覆盖场景详解

以下表格汇总了 `test_optimize.py` 中全部 11 个优化场景，涵盖不同方法、目标与权重组合：



| # | 场景 | 方法 | 权重特点 | 优化目标说明 |
|---|------|------|----------|-------------|
| 1 | 最大化夏普 | grid | 单目标，默认 `1.0` | 仅优化夏普比率，方向为最大化 |
| 2 | 最小化回撤 | grid | 单目标，`-1.0` | 仅优化最大回撤，负权重表示最小化方向 |
| 3 | 回撤+夏普等权 | grid | `(-1.0, 1.0)` | 同时优化回撤（最小化）与夏普（最大化），两者权重绝对值相等 |
| 4 | 三目标不同权重 | grid | `(-1.0, 3.0, 1.5)` | 夏普权重最高（3.0），回撤次之（-1.0），胜率再次（1.5） |
| 5 | 单目标贝叶斯 | optuna | 默认 | 使用 `TPESampler` 对 Calmar 比率进行单目标贝叶斯优化 |
| 6 | 全部最小化风险 | optuna | `(-1.0, -1.0, -1.0)` | 最大回撤、波动率、CVaR 三个风险指标全部最小化，使用 `NSGAIISampler` |
| 7 | 收益+风险平衡 | optuna | `(2.0, 1.5, 1.0, -1.0)` | 收益类指标（夏普、Sortino、Calmar）正向加权，回撤负向加权 |
| 8 | 偏好低波动 | optuna | `-2.0` | 单目标最小化波动率，高负权重表示极度厌恶波动 |
| 9 | 最小连亏次数 | optuna | `-1.0` | 以连续亏损次数为优化目标，负权重最小化，提升策略稳健性 |
| 10 | 利润因子+胜率 | optuna | `(2.0, 1.0)` | 利润因子权重为胜率的两倍，优先提升盈亏比 |
| 11 | 不设权重默认 | optuna | `None` | 不设置 `weights` 时，框架自动为所有目标分配等权重 `1.0`，方向均为最大化 |

### 场景结果分析

**示例 1~4（网格搜索）**

网格搜索通过穷举参数空间中所有组合，适合参数维度低、取值范围小的场景。示例 1 与 2 展示了单目标的最大化与最小化；示例 3 将回撤与夏普置于同一优化框架下，通过正负权重控制优化方向；示例 4 进一步引入三目标，并用 `3.0` 的高权重强调夏普比率的主导地位。

**示例 5~7（Optuna 贝叶斯优化）**

Optuna 利用贝叶斯推断高效采样，特别适合参数范围大、试验次数有限的场景。示例 5 为单目标 Calmar 优化；示例 6 采用 `NSGAIISampler` 处理三目标风险最小化问题；示例 7 展示了最复杂的多目标平衡配置，并开启 `HyperbandPruner` 提前剪枝劣质试验，同时设置 `n_jobs=-1` 利用全部 CPU 核心加速。

**示例 8~10（特定偏好优化）**

这三组示例针对特定交易偏好进行定向优化：示例 8 用 `-2.0` 的强负权重寻找低波动组合；示例 9 以连续亏损次数为目标，适合对资金曲线平滑度要求极高的策略；示例 10 同时关注利润因子与胜率，并赋予利润因子更高权重，确保盈亏比优先。

**示例 11（默认行为）**

当 `weights=None` 时，框架内部自动将所有目标权重设为 `1.0`，方向均为最大化。这是多目标优化的最简写法，适合快速验证或目标方向一致的场景。

## 四、OptimizationResult 结果对象

`signal_backtest` 在优化模式下返回 `OptimizationResult` 对象，提供以下核心接口：

| 方法 / 属性 | 说明 |
|------------|------|
| `best_params` | 最优参数字典 |
| `best_score` | 最优参数对应的主目标值 |
| `best_metrics` | 最优参数的完整指标字典 |
| `all_results` | 所有试验结果列表（仅 grid 模式） |
| `study` | Optuna Study 对象（仅 optuna 模式） |
| `.pprint()` | 格式化打印最优参数与指标 |
| `.to_dataframe()` | 返回试验结果 DataFrame |
| `.plot_optuna()` | 绘制 Optuna 优化历史（仅 optuna） |

## 五、注意事项

1. **参数范围格式**：
   - `grid` 模式使用 `(start, stop, step)` 三元组或列表 `['a', 'b', 'c']`。
   - `optuna` 模式使用 `(low, high)` 二元组定义连续搜索区间。

2. **权重方向**：
   - 正值表示**最大化**该指标，负值表示**最小化**。
   - 权重的绝对值大小代表相对重要性，用于多目标加权求和。

3. **多目标采样器**：
   - Optuna 多目标优化推荐使用 `NSGAIISampler`，单目标推荐使用 `TPESampler`。

4. **并行与导出**：
   - `n_jobs=-1` 可自动调用全部 CPU 核心，显著提升搜索速度。
   - `output_dir` 设置后，每次优化结果会自动导出为 CSV，便于后续对比分析。
