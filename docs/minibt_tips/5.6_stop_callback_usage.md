# minibt 使用技巧：@stop_callback 动态止损止盈回调装饰器

在 `signal_backtest` 中，除 `sl_stop`/`tp_stop` 等固定止损止盈外，`@stop_callback` 装饰器允许你编写**每根 K 线动态计算止损/止盈距离**的回调函数，经由 `numba.cfunc` 编译为 C 函数指针，在执行回测的 Cython 内核中高效调用。

## 一、装饰器签名与参数说明

使用 `@stop_callback` 装饰的函数必须遵循以下签名（返回值为 `float64`，表示新的止损/止盈距离）：

### 参数表

| 参数 | 类型 | 说明 |
|------|------|------|
| `bar_idx` | `int64` | 当前 K 线索引（0 起始） |
| `direction` | `int64` | 持仓方向：`1` = 多头，`-1` = 空头 |
| `entry_price` | `float64` | 开仓入场价 |
| `current_price` | `float64` | 当前 K 线价格 |
| `ref_price` | `float64` | 跟踪参考价（移动止损的基准价，初始为入场价） |
| `current_distance` | `float64` | 当前已有的止损/止盈距离（一般为 `sl_stop` 初始值或上一次回调返回值的绝对值） |
| `price_tick` | `float64` | 合约最小波动单位（如 `kline.price_tick`） |
| `volume_multiple` | `float64` | 合约乘数（如 `kline.volume_multiple`） |
| `size` | `float64` | 当前持仓手数 |
| `args_data` | `float64[:]` | 附加参数数组，由 `sl_callback_args` / `tp_callback_args` 展平而来 |
| `args_count` | `int64` | `args_data` 数组的总长度 |

### 返回值

| 返回值 | 含义 |
|--------|------|
| `> 0` | 设置新的止损/止盈距离（单位为 `price_tick`） |
| `<= 0` | 不改变当前止损/止盈距离（保持 `cur_dist`） |

> **重要**：止损距离始终按 tick 单位计算，应用时由底层自动乘以 `price_tick`。例如 `return 5.0` 表示 5 个 tick。

## 二、基本使用方式

### 1. 固定止损/止盈（最简单）

```python
from minibt import stop_callback, LocalDatas, IndSeries

kline = LocalDatas.l2601_60.kline
ind = IndSeries(kline)

# 计算 CCI 信号
c = ind.close.cci(10)
long_sig = c.cross_up(100)
short_sig = c.cross_down(-100)
ind.add_signal(long_sig, short_sig)

@stop_callback
def fixed_sl(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    # 固定 5 个 tick 止损
    return 5.0

@stop_callback
def fixed_tp(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    # 固定 20 个 tick 止盈
    return 20.0

result = ind.signal_backtest(
    sl_callback=fixed_sl,
    tp_callback=fixed_tp,
)
```

### 2. 按方向差异化止损（多头/空头不同距离）

```python
@stop_callback
def direction_aware_sl(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    if direction == 1:    # 多头
        return 3.0        # 窄止损
    else:                 # 空头
        return 5.0        # 宽止损
```

### 3. 基于当前价格动态计算止损距离

```python
@stop_callback
def price_based_sl(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    # 多头的浮动亏损超过入场价 2% 时触发止损
    if direction == 1:
        loss_pct = (entry - price) / entry
        if loss_pct > 0.02:
            return 1.0           # 触发最小止损立即离场
    return 0.0                    # 不改变
```

## 三、传递附加参数（`sl_callback_args`）

通过 `sl_callback_args` 可以传入**每根 K 线动态变化的数组**或**标量常数**，在回调中通过 `args_data` 访问。

### 单个数组：每 bar 不同的止损距离

```python
import numpy as np
from minibt import stop_callback

n = len(kline)
# 构建每 bar 动态止损数组：前一半 3 tick，后一半 8 tick
dynamic_sl = np.full(n, 3.0)
dynamic_sl[n // 2:] = 8.0

@stop_callback
def per_bar_sl(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    if args_count > bar_idx:
        return args_data[bar_idx]          # 读取当前 bar 对应的止损 tick 数
    return 0.0

result = ind.signal_backtest(
    sl_callback=per_bar_sl,
    sl_callback_args=(dynamic_sl,),
)
```

### 标量 + 数组混合：基值 × 动态乘数

```python
n = len(kline)
# atr_mult 随时间从 0.5 逐渐增大到 2.0
atr_mult = np.linspace(0.5, 2.0, n)

@stop_callback
def hybrid_sl(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    # args_data[0]         = base_tick（标量常数）
    # args_data[1 : 1+n]   = atr_mult 数组
    if args_count < 1 + n + 1:
        return 0.0
    base = args_data[0]
    coef = args_data[1 + bar_idx]
    return base * coef                     # 基础 tick × 动态系数

result = ind.signal_backtest(
    sl_callback=hybrid_sl,
    sl_callback_args=(5.0, atr_mult),      # 5 tick 基础 × atr_mult 乘数
)
```

> **`args_data` 布局规则**：`sl_callback_args=(a, b, c, ...)` 中，标量值直接占一个元素，`ndarray` 按顺序展平。例如 `(3.0, arr_100)` → `args_data[0] = 3.0`，`args_data[1:101] = arr_100[:]`，`args_count = 101`。

## 四、回调函数编写注意事项

1. **保持纯 Python 数值运算**：回调会被 `numba` 编译为 C 代码（nopython 模式），避免使用不支持的高级 Python 特性及 numpy 复杂操作
2. **返回值单位是 tick**：返回 `5.0` 表示 5 个 tick，不是价格绝对值
3. **`cur_dist` 是当前已设置的止损距离**：可用于判断"是否已经触发过一次回调"
4. **返回 `0.0` 保持现状**：如果不需要修改止损/止盈距离，返回 `<= 0` 即可
5. **`sl_callback` 和 `tp_callback` 可同时使用**：分别控制止损和止盈，签名完全相同
6. **与固定止损/止盈参数共存**：`sl_callback` 可与 `sl_stop`、`sl_trail` 等同时使用，回调返回值优先级最高
7. **性能考虑**：回调在每个持仓 bar 上都会被调用，避免在回调内部做繁重迭代

## 五、完整实战示例

以下示例展示了一个完整的 ATR 动态止损策略：

```python
from minibt import *

kline = LocalDatas.l2601_60.kline
tick = kline.price_tick

# ===== 构建 CCI 信号 =====
ind = IndSeries(kline)
c = ind.close.cci(10)
long_sig = c.cross_up(100)
short_sig = c.cross_down(-100)
ind.add_signal(long_sig, short_sig)

# ===== 计算 ATR 作为动态基准 =====
atr_arr = ind.close.atr(14).to_numpy()

@stop_callback
def atr_trail_sl(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    """
    基于 ATR 的动态移动止损：
    - args_data[bar_idx] = 当前 bar 的 ATR 值
    - 止损距离 = max(1.5 × ATR, 3 tick)，至少 3 个 tick
    """
    if args_count <= bar_idx:
        return 0.0
    atr_val = args_data[bar_idx]
    dist = max(1.5 * atr_val / tick, 3.0)  # ATR 转 tick + 最小保底
    return dist

@stop_callback
def atr_tp(bar_idx, direction, entry, price, ref, cur_dist, tick, mult, size, args_data, args_count):
    """ATR 止盈：3 倍 ATR"""
    if args_count <= bar_idx:
        return 20.0                       # 默认 20 tick 止盈
    atr_val = args_data[bar_idx]
    return max(3.0 * atr_val / tick, 5.0)

result = ind.signal_backtest(
    sl_callback=atr_trail_sl,
    tp_callback=atr_tp,
    sl_callback_args=(atr_arr,),
    tp_callback_args=(atr_arr,),
)
result.pprint()
```

## 六、全参数综合示例：逐参数详解

以下示例展示了如何在一个 `stop_callback` 中使用**全部 11 个参数**，实现一个融合同趋势、ATR 波动率、持仓规模和盈亏管理的复合止损策略。

```python
from minibt import *
import numpy as np

kline = LocalDatas.l2601_60.kline
tick = kline.price_tick
ind = IndFrame()

# ===== 构建信号 =====
ma_fast = kline.close.sma(5)
ma_slow = kline.close.sma(20)
long_sig = ma_fast.cross_up(ma_slow)
short_sig = ma_fast.cross_down(ma_slow)
ind.long_signal = long_sig
ind.short_signal = short_sig

# ===== 构建附加参数 =====
n = len(kline)
atr_arr   = ind.close.atr(14).to_numpy()         # 数组①: 每 bar 的 ATR
vol_arr   = ind.close.sma(20).to_numpy()          # 数组②: 均线基准
min_tick  = 3.0                                    # 标量③: 最小保底 tick 数
max_tick  = 50.0                                   # 标量④: 最大止损 tick 上限
pct_limit = 0.03                                   # 标量⑤: 亏损百分比阈值

@stop_callback
def full_param_sl(
    bar_idx,          # ① 当前 K 线索引：用于查找 args_data 中当前 bar 的 ATR
    direction,        # ② 持仓方向：1=多头 / -1=空头，决定止损计算的正负逻辑
    entry,            # ③ 入场价：用于计算"浮动亏损百分比"
    price,            # ④ 当前价：配合 entry 计算实时盈亏
    ref,              # ⑤ 跟踪参考价（移动止损基准价）：判断是否需要"收紧"止损
    cur_dist,         # ⑥ 当前止损距离（tick 单位）：避免止损距离越调越宽
    tick,             # ⑦ 最小波动单位：将价格差值 / ATR 值换算为 tick 数
    mult,             # ⑧ 合约乘数：结合 price 和 size 估算持仓市值，影响止损容忍度
    size,             # ⑨ 当前持仓手数：手数越大，适当放宽止损（避免被噪音震出）
    args_data,        # ⑩ 附加参数展平数组：包含 atr_arr、vol_arr 和 3 个标量
    args_count        # ⑪ 附加参数数组总长度：用于边界安全检查，防止越界读取
):
    # ---------- 边界安全 ----------
    # 使用 args_count 确保 bar_idx 不越界（防止数组访问错误）
    if args_count < n + n + 3:      # = len(atr) + len(vol) + 3 个标量
        return 0.0
    if bar_idx < 0 or bar_idx >= n:
        return 0.0

    # ---------- 从 args_data 读取附加参数 ----------
    # args_data 布局：[0:n] = atr_arr, [n:2n] = vol_arr,
    #                [2n] = min_tick, [2n+1] = max_tick, [2n+2] = pct_limit
    atr_val    = args_data[bar_idx]          # 当前 bar 的 ATR（波动率度量）
    vol_ref    = args_data[n + bar_idx]       # 当前 bar 的均线参考价
    min_tick_v = args_data[2 * n]             # 最小止损 tick 保底
    max_tick_v = args_data[2 * n + 1]         # 最大止损 tick 上限
    pct_lim    = args_data[2 * n + 2]         # 亏损百分比阈值

    # ---------- 基于 direction 的分向逻辑 ----------
    if direction == 1:                        # === 多头侧 ===
        # --- 利用 entry 和 price 计算浮动亏损 ---
        # 当前亏损百分比 = (入场价 - 当前价) / 入场价
        loss_pct = (entry - price) / entry

        # --- pct_limit 触发硬止损 ---
        # 亏损超过阈值（如 3%）时，立即以最小 tick 止损离场
        if loss_pct >= pct_lim:
            return 1.0          # 1 tick = 立刻止损（触发后成交价最接近当前价）

        # --- 利用 ref（跟踪参考价）实现移动止盈 ---
        # 多头中 ref 会跟踪行情新高；当价格跌破 ref 一定幅度时收紧止损
        if price < ref and cur_dist > 0:
            # 价格已跌破参考价，计算"保护性距离"
            protect_dist = (ref - price) / tick
            if protect_dist < cur_dist:
                # 只收紧、不放宽：当前止损距离较大时才收紧
                return max(protect_dist, 1.0)

        # --- ATR 动态止损（利用 price_tick 换算） ---
        # 基础 = 2 x ATR，除以 tick 转为 tick 单位
        raw_dist = 2.0 * atr_val / tick

    else:                                     # === 空头侧 ===
        loss_pct = (price - entry) / entry
        if loss_pct >= pct_lim:
            return 1.0

        if price > ref and cur_dist > 0:
            protect_dist = (price - ref) / tick
            if protect_dist < cur_dist:
                return max(protect_dist, 1.0)

        raw_dist = 2.0 * atr_val / tick

    # ---------- 利用 volume_multiple 和 size 做仓位规模修正 ----------
    # 持仓市值 = price × mult × size
    # 市值越大，止损适当放宽（×1.0~1.5），避免小波动震出
    position_value = price * mult * size
    # 以 10 万元为基准：市值每超过基准 10 万，放宽 5%
    scale_factor = 1.0 + max(0.0, (position_value - 100_000) / 100_000 * 0.05)
    scale_factor = min(scale_factor, 1.5)      # 最多放宽 50%

    adjusted_dist = raw_dist * scale_factor

    # ---------- 利用 cur_dist：只收紧、不放宽 ----------
    # 新的止损距离不能比当前宽（防止止损越跑越远）
    if cur_dist > 0 and adjusted_dist > cur_dist:
        adjusted_dist = cur_dist

    # ---------- min_tick / max_tick 限幅 ----------
    # 利用 min_tick_v 保证最小止损距离，利用 max_tick_v 防止止损过远
    final_dist = max(min_tick_v, min(adjusted_dist, max_tick_v))

    return final_dist


# ===== 调用 =====
result = ind.signal_backtest(
    sl_callback=full_param_sl,
    # args_data 布局：atr_arr（n 个）+ vol_arr（n 个）+ 3 个标量 = 2n+3 个元素
    sl_callback_args=(atr_arr, vol_arr, min_tick, max_tick, pct_limit),
)
result.pprint()
```

### 参数使用对照表

| 参数 | 在本例中的作用 |
|------|---------------|
| `bar_idx` | 作为索引从 `args_data` 中取出当前 bar 的 ATR 和均线值 |
| `direction` | 分支判断：多头用 `entry - price`、空头用 `price - entry` 计算亏损 |
| `entry` | 计算浮动亏损百分比 `loss_pct` 的基准价 |
| `price` | 计算实时盈亏、持仓市值 |
| `ref` | 移动止损基准价：价格不利突破 `ref` 时收紧止损距离 |
| `cur_dist` | 保护逻辑：新止损距离 **不可大于** 当前距离（只紧不松） |
| `tick` | 价格差值 → tick 数转换（`价差 / tick`），返回值单位归一化 |
| `mult` | 参与持仓市值计算 `price × mult × size` |
| `size` | 参与仓位规模修正：持仓越大止损稍宽，避免噪音震出 |
| `args_data` | 展平数组，承载 ATR、均线和 3 个标量配置参数 |
| `args_count` | 边界检查：防止 `bar_idx` 越界导致 `args_data` 读取越界 |

## 七、核心总结

| 要点 | 说明 |
|------|------|
| 装饰器 | `@stop_callback` 自动编译为 numba C 函数指针 |
| 适用范围 | 同时适用于 `sl_callback=`（止损）和 `tp_callback=`（止盈） |
| 返回值 | 正数 = 新止损距离（tick 单位），`<= 0` = 保持不变 |
| 附加参数 | 通过 `sl_callback_args=(...)` 传入，标量与数组混传自动展平 |
| 效率 | 回调编译为 native C 代码，在 Cython 回测内核中无开销调用 |
| 组合 | 可与 `sl_stop`、`sl_trail`、`tp_stop`、`max_hold_bars` 等参数共存 |
