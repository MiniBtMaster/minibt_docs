# minibt 指标使用最佳实践与布林带策略完整示例

## 概述

本文档总结了 minibt 中编写技术指标与策略的**正确模式**，并以布林带(Bollinger Bands)为例提供完整可运行代码。所有 LLM 生成的策略代码都**必须**遵循本文档中的模式。

---

## 一、两种正确的指标使用模式

### 模式 A：BtIndicator + Strategy（推荐）

**核心约定：**
- BtIndicator 继承自 `BtIndicator`
- 在 `next()` 中使用链式方法计算指标（如 `self.close.bbands()`、`self.close.sma()`）
- 通过 `return` 返回计算结果，变量名自动暴露为属性
- 信号使用 `.cross_up()` / `.cross_down()` 生成布尔序列
- 策略中通过 `self.indicator.信号名.new` 读取最新信号

**布林带突破完整示例（正确写法）：**

```python
from minibt import *


class BollingerBreakout(BtIndicator):
    """布林带突破指标"""
    params = dict(BB_PERIOD=20, BB_STD=2)
    isplot = dict(long_signal=False, short_signal=False)
    overlap = True

    def next(self):
        # 使用链式方法计算布林带，返回 IndFrame，直接解包
        upper, middle, lower = self.close.pta.bbands(
            self.params.BB_PERIOD, self.params.BB_STD)
        # 生成突破信号
        long_signal = self.close.cross_up(upper)
        short_signal = self.close.cross_down(lower)
        # return 的变量自动成为 self.indicator.xxx 属性
        return upper, middle, lower, long_signal, short_signal


class BollingerBreakoutStrategy(Strategy):

    def __init__(self):
        self.min_start_length = 300
        self.data = self.get_kline(LocalDatas.v2601_300, height=500)
        self.bb = BollingerBreakout(self.data)

    def next(self):
        if not self.data.position:
            if self.bb.long_signal.new:
                self.data.buy(stop=BtStop.SegmentationTracking)
            elif self.bb.short_signal.new:
                self.data.sell(stop=BtStop.SegmentationTracking)


if __name__ == "__main__":
    Bt().run()
```

### 模式 B：Strategy 内联指标

**核心约定：**
- 在 Strategy 的 `__init__()` 中直接计算指标
- 计算结果保存为 `self.xxx` 属性
- 通过 `self.xxx.new` 读取最新信号
- 信号序列需要设置 `self.xxx.isplot = False` 避免绘图干扰

```python
from minibt import *


class BollingerBreakoutStrategy(Strategy):
    params = dict(BB_PERIOD=20, BB_STD=2)

    def __init__(self):
        self.min_start_length = 300
        self.data = self.get_kline(LocalDatas.v2601_300, height=500)
        # 链式方法计算布林带
        bb = self.data.close.pta.bbands(
            self.params.BB_PERIOD, self.params.BB_STD)
        self.upper, self.middle, self.lower = bb.upper, bb.mid, bb.lower
        # 生成信号
        self.long_signal = self.data.close.cross_up(self.upper)
        self.short_signal = self.data.close.cross_down(self.lower)
        self.long_signal.isplot = False
        self.short_signal.isplot = False

    def next(self):
        if not self.data.position:
            if self.long_signal.new:
                self.data.buy(stop=BtStop.SegmentationTracking)
            elif self.short_signal.new:
                self.data.sell(stop=BtStop.SegmentationTracking)


if __name__ == "__main__":
    Bt().run()
```

## 二、布林带 (Bollinger Bands) 三种 API 对比

minibt 提供了三种布林带 API，**必须使用链式调用**，不存在独立的 `BOLL` 类或函数：

| API 路径 | 用法 | 返回列名 | 适用场景 |
|----------|------|----------|----------|
| `self.close.pta.bbands(length, std)` | PandasTA | `lower, mid, upper, bandwidth, percent` | 推荐，最丰富 |
| `self.close.tqta.BOLL(n, p)` | 天勤 | `c, mid, top, bottom` | 简洁 |
| `self.close.talib.BBANDS(timeperiod, nbdevup, nbdevdn)` | TA-Lib | `upperband, middleband, lowerband` | 专业 |

**关键规则：不存在 `from minibt.indicators import BOLL` 或独立的 `BOLL()` 函数调用。**

## 三、核心 API 速查

### 3.1 K 线数据的链式方法（在 BtIndicator.next() 中 self 继承自 KLine）

```python
# === 可直接访问的 K 线属性 ===
self.close    # 收盘价 IndSeries
self.high     # 最高价 IndSeries
self.low      # 最低价 IndSeries
self.open     # 开盘价 IndSeries
self.volume   # 成交量 IndSeries

# === 常用链式指标方法 ===
self.close.sma(period)        # 简单移动平均
self.close.ema(period)        # 指数移动平均
self.close.rsi(period)        # RSI 相对强弱
self.close.cci(period)        # CCI 商品通道指数
self.close.atr(period)        # ATR 平均真实波幅
self.close.cmo(period)        # Chande 动量振荡器
self.close.wma(period)        # 加权移动平均

# === 第三方 API ===
self.close.pta.bbands(n, m)   # PandasTA 布林带 ★推荐
self.close.pta.macd()         # PandasTA MACD
self.close.tqta.BOLL(n, p)    # 天勤布林带
self.close.talib.BBANDS(t)    # TA-Lib 布林带

# === 信号生成方法 ===
self.close.cross_up(threshold)    # 上穿，返回布尔 IndSeries
self.close.cross_down(threshold)  # 下穿，返回布尔 IndSeries

# === 数据操作方法 ===
self.close.shift(n)           # 偏移 n 根 K 线
self.close.diff(n)            # n 阶差分
self.close.rolling(window)    # 滚动窗口
```

### 3.2 信号访问约定

```python
# 在 BtIndicator 中通过 return 返回的信号：
#   return upper, lower, long_signal, short_signal
# 
# 在 Strategy 中访问：
#   self.my_ind.long_signal      # 整个信号序列
#   self.my_ind.long_signal.new  # 最新一根 K 线的信号值 (True/False)
#   self.my_ind.long_signal.prev # 上一根 K 线的信号值

# 在 Strategy 内联中：
#   self.long_signal      # 整个信号序列
#   self.long_signal.new  # 最新一根 K 线的信号值
```

### 3.3 交易操作

```python
# 在 Strategy.next() 中：
self.data.buy()                         # 开多
self.data.sell()                        # 开空
self.data.buy(stop=BtStop.SegmentationTracking)  # 开多+分段跟踪止损
self.data.close()                       # 平仓
self.data.position                      # 当前持仓 (0=无, >0=多, <0=空)
```

## 四、常见错误与纠正

| 错误 | 正确 |
|------|------|
| `from minibt.indicators import BOLL` | minibt 没有 BOLL 模块！使用链式方法 `self.close.pta.bbands()` |
| `BOLL(self.close, n, p)` 函数调用 | `self.close.pta.bbands(length=n, std=p)` |
| `indicator = BollingerBreakout(data)` | 正确：`self.bb = BollingerBreakout(self.data)` |
| `self.buy_signal.new` (变量名错) | `return` 中的变量名即属性名：`return break_buy, ...` → `self.ind.break_buy.new` |
| 在 `next()` 中重复计算指标 | 应在 `__init__()` 或 BtIndicator.next() 中计算，信号序列是全量预计算的 |

## 六、总结

1. **永远使用链式方法**：`self.close.指标名(参数)`，不存在独立的指标类或函数
2. **信号用 `.cross_up()` / `.cross_down()`**：标准、高效
3. **`.new` 获取最新信号**：`self.indicator.signal_name.new`
4. **`return` 暴露变量**：BtIndicator.next() 中 return 的变量名即 Strategy 中访问的属性名
5. **`params` 声明可调参数**：使用 `self.params.XXX` 访问
6. **从 `minibt import *` 导入**：包含所有必要类和函数
