# 主界面介绍

## 2.1 整体布局

MiniQT 采用 Fluent Design 风格，界面主要分为以下几个部分：

```text
┌─────────────────────────────────────────────────────────────────┐
│  标题栏 (Logo + 菜单按钮 + 标签栏 + 登录状态)                     │
├───────────────┬─────────────────────────────────────────────────┤
│     导航栏     │                主内容区域                        │
│               │                                                 │
│   ● 主页       │                                                 │
│   ● 行情报价   │                                                  │
│   ● 策略回测   │                                                  │
│               │                                                  │
│   ● minibt官网 │                                                 │
│   ● 设置       │                                                 │
└───────────────┴──────────────────────────────────────────────────┘
```

## 2.2 标题栏

[CustomTitleBar](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/main_window.py#L529) 位于窗口顶部，包含以下元素：

| 元素         | 说明                                                              |
| ------------ | ----------------------------------------------------------------- |
| Logo         | MiniQT 应用图标，支持深色/浅色模式自适应                          |
| 菜单按钮     | 点击可展开登录菜单，包含期货登录、股票登录等选项                  |
| 标签栏       | 显示当前打开的子窗口（K线图表、终端、Jupyter 等），支持拖拽和关闭 |
| 添加按钮 (+) | 快捷入口，可快速打开新的子窗口（终端、Jupyter、K线等）            |

### 2.2.2 "+" 快捷入口

标题栏右侧的 "+" 按钮提供快速打开新窗口的功能：

1. 点击 "+" 按钮弹出下拉菜单
2. 选择要打开的窗口类型（终端、Jupyter、JupyterLab、K线图表等）
3. 窗口会在标签栏中新增一个标签

### 2.2.3 标签栏

标签栏管理所有打开的子窗口：

- **切换标签**：点击标签切换到对应子窗口
- **关闭标签**：点击标签上的关闭按钮
- **拖拽排序**：拖拽标签可以调整顺序
- **滚动浏览**：标签过多时支持滚动

## 2.3 导航栏

导航栏位于界面左侧，通过 [initNavigation](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/main_window.py#L957) 初始化，包含以下导航项：

### 2.3.1 顶部导航项

#### 主页 (`Home`)

[HomeInterface](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/home_interface.py#L100) 是默认显示的界面，包含：

- **Banner 区域**：展示项目名称 "Mini Quant Trader" 和 K 线背景图
- **资源链接**：GitHub 仓库、PyPI 仓库、在线教程、知乎专栏的快速链接
- **快捷入口卡片**：行情报价、策略回测、minibt 官网、系统设置
- **登录接口卡片**：期货登录、股票登录
- **开发工具卡片**：终端窗口、Jupyter 窗口、JupyterLab 窗口

#### 行情报价 (`marketQuoteInterface`)

[MarketQuoteInterface](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/market_quote_interface.py#L41) 展示各交易所的合约列表：

- 按交易所和品种分类展示合约
- 支持列排序、右键菜单快速打开 K 线图
- 双击合约可直接打开 K 线图表

![miniqt 行情报价界面](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_2.png)


#### 策略回测 (`strategyBacktestInterface`)

[StrategyBacktestWindow](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/windows/strategy_backtest_window.py) 提供策略开发与回测环境：

- 代码编辑器（支持 Python 语法高亮）
- 回测结果图表展示
- 参数优化功能

![miniqt 策略回测界面](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_4.png)

### 2.3.2 底部导航项

底部导航项（[NavigationItemPosition.BOTTOM](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/main_window.py#L987)）位于导航栏下方：

#### minibt 官网 (`officialWebsite`)

内嵌浏览器（QWebEngineView），直接访问 minibt 官方网站，获取最新资讯和文档。

![miniqt minibt 官网](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_5.png)

#### 设置 (`Settings`)

[SettingInterface](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/setting_interface.py) 提供全局配置：


- **主题切换**：亮色/暗色模式
- **数据源配置**：期货、股票数据源设置
- **图表样式**：K 线颜色、字体等参数
- **全局参数**：通用应用设置

![miniqt 设置界面](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_17.png)
