# K 线图表使用详解

## 6.1 打开 K 线图表

有以下几种方式可以打开 K 线图表：

### 方式一：从行情报价打开

1. 进入「行情报价」模块
2. 在合约列表中双击目标合约
3. 如果 API 未连接，会弹出登录窗口
4. 登录成功后自动打开 K 线图表

### 方式二：从快捷入口打开

1. 在主页的「快捷入口」中点击「行情报价」进入
2. 或使用标题栏的 "+" 按钮快速进入

### MarketWatchWindow 看盘窗口

[MarketWatchWindow](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/windows/market_watch_window.py) 是看盘模块的核心窗口，负责管理 K 线图表的创建和布局：

```python
# 创建看盘窗口
market_watch = MarketWatchWindow(
    parent=main_window,
    symbol="SHFE.cu2409",  # 合约代码
    cycle=60,              # K 线周期（秒）
    length=1000,           # K 线数量
    is_stock=False         # False=期货, True=股票
)
```

![miniqt 看盘窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_10.png)

看盘窗口使用 [Chart](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/windows/chart_interface.py) 作为图表组件，基于 Lightweight Charts 渲染高性能 K 线图。

## 6.2 添加更多 K 线图表

看盘窗口支持多图表布局，使用 [_ToggleButtonSplitter](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/windows/strategy_backtest_window.py) 实现可拖拽分割。

### 添加方式

| 操作         | 方法                                    |
| ------------ | --------------------------------------- |
| **右侧添加** | 点击工具栏的「+」按钮，新图表添加到右侧 |
| **下方添加** | 右键点击分割线，选择「下方添加」        |
| **关闭图表** | 点击窗口右上角的关闭按钮                |

### 布局调整

- **拖拽分割线**：调整相邻图表的大小比例
- **多图表联动**：同一合约不同周期的图表可以联动操作

### 工具栏功能

看盘窗口的工具栏提供以下功能按钮：

- **周期切换**：30秒、1分钟、5分钟、15分钟、1小时、1日
- **指标管理**：添加/删除技术指标
- **画线工具**：水平线、趋势线、通道线等
- **图表设置**：K 线样式、颜色主题等

![miniqt 多图表布局窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_11.png)

## 6.3 使用指标

### 添加指标

1. 点击图表工具栏的「指标」按钮
2. 在指标列表中选择目标指标
3. 设置指标参数（如周期、倍数等）
4. 点击确定，指标会显示在图表上

### 指标类型

指标通过 `overlap` 参数控制显示位置：

| 类型     | overlap 值 | 显示位置     | 示例                     |
| -------- | ---------- | ------------ | ------------------------ |
| 主图指标 | `True`     | K 线主图上   | 均线 (MA)、布林带 (BOLL) |
| 副图指标 | `False`    | K 线下方子图 | MACD、RSI、成交量        |

![miniqt 指标窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_12.png)

### 混合指标

部分指标支持同时在主图和副图显示，例如 AndeanOsc 指标：

```python
@tobtind(
    lines=["up", "dn", "bull", "bear", "signal"], 
    overlap=dict(up=True, dn=True, bull=False, bear=False, signal=False), 
    lib="btind"
)
def AndeanOsc(self, length=14, signal_length=9):
    """安第斯振荡器指标"""
    ...
```

其中 `overlap=True` 的指标线（`up`、`dn`）显示在主图，`overlap=False` 的指标线（`bull`、`bear`、`signal`）显示在副图。

指标通过 [Chart.add_indicator](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/windows/chart_interface.py) 方法添加到图表中，系统会自动根据 `overlap` 配置将指标线分配到对应区域。

### 删除指标

1. 将鼠标移动到左上角的指标标签上（蓝色/红色文字）
2. 点击标签右侧的眼睛图标可隐藏/显示指标
3. 右键点击指标标签（minibt 指标），选择「删除」可移除指标

## 6.4 画线工具

### 使用画线工具

1. 点击图表工具栏的「画线」按钮
2. 选择画线工具类型：

   - **水平线**：标记支撑/阻力位
   - **趋势线**：连接高/低点绘制趋势
   - **平行通道**：绘制价格通道
3. 在图表上拖拽绘制线条
4. 双击线条可调整位置和属性

### 管理画线

- **编辑**：双击已画线条进入编辑模式
- **删除**：右键点击线条，选择「删除」
- **清除全部**：点击工具栏「清除画线」按钮

## 6.5 图表操作

### 周期切换

点击图表顶部的周期按钮切换 K 线周期：

| 周期   | 说明                    |
| ------ | ----------------------- |
| 30秒   | 30 秒 K 线（超短线）    |
| 1分钟  | 1 分钟 K 线             |
| 5分钟  | 5 分钟 K 线（日内短线） |
| 15分钟 | 15 分钟 K 线            |
| 1小时  | 1 小时 K 线             |
| 1日    | 日线（趋势交易）        |

### 缩放与平移

| 操作      | 方法                 |
| --------- | -------------------- |
| 放大/缩小 | 鼠标滚轮上下滚动     |
| 平移图表  | 按住鼠标左键左右拖拽 |
| 恢复默认  | 双击图表空白区域     |

### 十字光标

鼠标在图表上移动时：

- 显示十字光标，精确标注当前价格和时间
- 左上角显示各指标线的当前值
- 主图显示价格信息（开、高、低、收、量）

### 数据导出

右键点击图表，可选择：

- 导出 K 线数据到文件
- 导出交易记录到 CSV

## 6.6 键盘精灵

键盘精灵是快速搜索和打开合约、指标的强大工具，支持期货、股票和指标的模糊搜索。

### 打开方式

| 操作     | 方法                   |
| -------- | ---------------------- |
| 快捷键   | 在看盘窗口按 `空格` 键 |
| 菜单入口 | 点击工具栏的搜索图标   |

### 搜索类型

键盘精灵支持以下搜索类型：

| 类型         | 前缀            | 示例                        | 说明                                                 |
| ------------ | --------------- | --------------------------- | ---------------------------------------------------- |
| **期货合约** | 无需前缀        | `cu2409`、`rb2410`          | 支持上期所、大商所、郑商所、中金所、能源中心、广期所 |
| **股票**     | `stock:` 或 `.` | `stock:000001` 或 `.000001` | A股股票代码                                          |
| **指标**     | `ind:` 或 `@`   | `ind:MA` 或 `@MACD`         | 技术指标名称                                         |

### 期货合约搜索

直接输入合约代码或简称，系统会自动匹配：

- **完整代码**：`SHFE.cu2409` → 上期所沪铜2409
- **简写代码**：`cu2409` → 自动识别为 `SHFE.cu2409`
- **品种简称**：`沪铜`、`铜`、`CU` 均可匹配铜系列合约

支持交易所标识：
| 标识    | 交易所               |
| ------- | -------------------- |
| `SHFE`  | 上海期货交易所       |
| `DCE`   | 大连商品交易所       |
| `CZCE`  | 郑州商品交易所       |
| `CFFEX` | 中国金融期货交易所   |
| `INE`   | 上海国际能源交易中心 |
| `GFEX`  | 广州期货交易所       |

### 股票搜索

输入股票代码或名称进行搜索：
- **股票代码**：`000001` → 平安银行
- **带前缀**：`stock:000001` 或 `.000001`
- **股票名称**：`平安银行`、`茅台`、`宁德时代`

### 指标搜索

输入指标名称快速添加指标到当前图表：
- **带前缀**：`ind:MA` 或 `@MACD`
- **直接输入**：`MA`、`MACD`、`BOLL` 等

### 快捷键操作

| 快捷键    | 功能             |
| --------- | ---------------- |
| `空格`    | 启动键盘精灵     |
| `↑` / `↓` | 上下选择搜索结果 |
| `Enter`   | 确认选择         |
| `Esc`     | 关闭键盘精灵     |

### 使用示例

1. 在看盘窗口按 `空格` 键打开键盘精灵
2. 输入 `cu2409` 搜索沪铜2409合约
3. 按 `Enter` 打开该合约的 K 线图表
4. 再次按 `空格`，输入 `@MA` 添加均线指标
