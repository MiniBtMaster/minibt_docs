# 开发工具

## 5.1 终端窗口

### 功能介绍

终端窗口提供交互式命令行界面，用于执行系统命令和 Python 脚本。

### 打开方式

1. 在主页的「开发工具」卡片中点击「终端窗口」
2. 或通过标题栏的「+」按钮选择「终端窗口」
3. 或通过标题栏菜单选择「终端窗口」

### 核心特性

- 内置终端模拟器，支持 PowerShell 命令
- 输出实时显示在窗口中
- 支持交互命令（如 Python REPL）
- 支持复制粘贴操作

![miniqt 终端窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_6.png)

## 5.2 Jupyter 窗口

### 功能介绍

Jupyter Notebook 提供交互式编程环境，适合策略开发和数据分析。

### 打开方式

1. 在主页的「开发工具」卡片中点击「Jupyter 窗口」
2. 或通过标题栏的「+」按钮选择「Jupyter 窗口」
3. 或通过标题栏菜单选择「Jupyter 窗口」

### 核心特性

- 集成 Jupyter Notebook，无需额外安装和配置
- 支持 Python 交互式编程
- 可创建和运行 Notebook 文件
- 支持富文本输出（图表、表格、Markdown 等）
- 适合数据分析和策略验证

![miniqt Jupyter 窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_7.png)

## 5.3 JupyterLab 窗口

### 功能介绍

JupyterLab 是比 Jupyter Notebook 更强大的交互式开发环境。

### 打开方式

1. 在主页的「开发工具」卡片中点击「JupyterLab 窗口」
2. 或通过标题栏的「+」按钮选择「JupyterLab 窗口」
3. 或通过标题栏菜单选择「JupyterLab 窗口」

### 核心特性

- 多标签页界面，支持同时打开多个文件
- 文件浏览器：浏览、创建、删除文件和目录
- 代码编辑器：支持 Python 语法高亮和代码补全
- 终端集成：内置终端模拟器
- 支持 Notebook、Python 脚本、Markdown 等多种文件格式

![miniqt JupyterLab 窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_8.png)

## 5.4 开发工具对比

| 特性     | 终端窗口 | Jupyter 窗口 | JupyterLab 窗口     |
| -------- | -------- | ------------ | ------------------- |
| 代码执行 | 命令行   | 交互式单元格 | 交互式单元格 + 脚本 |
| 文件管理 | 命令行   | 有限         | 完整浏览器          |
| 多标签   | 否       | 否           | 是                  |
| 终端集成 | 是       | 否           | 是                  |
| 适用场景 | 系统命令 | 数据探索     | 项目开发            |
