# 期货与股票数据切换

MiniQT 同时支持期货和股票两种数据源，两者使用相同的图表界面和操作方式，但在底层实现上有显著区别。

---

## 7.1 期货数据（TqApi）

### 数据源

- **API**：天勤 TqSdk 的 [TqApi](https://www.shinnytech.com/tqsdk/)
- **协议**：WebSocket
- **模块**：[tq_object.py](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/common/tq_object.py)

### 连接方式

1. 点击导航栏或主页的「期货登录」
2. 输入天勤期货账户用户名和密码
3. 登录成功后，系统自动获取合约列表和实时行情
4. 同时将合约信息同步到本地 DuckDB 数据库

![miniqt 期货登录窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_15.png)

### 合约格式

```
交易所.合约代码
示例：SHFE.cu2409、CZCE.SR409、DCE.m2409
```

其中：

- SHFE = 上海期货交易所
- CZCE = 郑州商品交易所
- DCE = 大连商品交易所
- INE = 上海国际能源交易中心

### 更新机制

期货数据的实时更新由 [TqApiQTimer](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/main_window.py#L749) 驱动：

1. 定时器每 50ms 触发一次 `wait_update()`
2. `TqApi.wait_update()` 从 WebSocket 获取最新数据
3. 数据更新后通过 [ChartUpdateManager](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/main_window.py#L256) 同步到所有图表
4. K 线图表和行情报价表自动刷新

### K 线数据时间处理

期货 K 线数据来自 TqApi 的 WebSocket 推送：

- 时间是 **UTC 时间**，需要在显示时 **加 8 小时** 转换为北京时间
- 支持集合竞价数据（夜盘），时间范围覆盖 24 小时
- K 线包含完整的交易时段数据

## 7.2 股票数据（MooTDX）

### 数据源

- **协议**：MooTDX（TCP 连接）
- **模块**：[stock_api.py](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/common/stock_api.py)

StockApi 的设计模仿了 TqApi 的接口，提供一致的 `get_kline_serial()`、`wait_update()` 等方法。

### 连接方式

1. 点击导航栏或主页的「股票登录」
2. 系统自动通过 MooTDX TCP 协议连接通达信行情服务器
3. 使用预定义服务器列表快速初始化，减少启动时间
4. 连接成功后即可获取股票实时行情

![miniqt 股票登录窗口](https://minibt-img.oss-cn-shenzhen.aliyuncs.com/plot/6_16.png)

### 合约格式

```
市场.股票代码
示例：SSE.600897、SZSE.000001
```

其中：

- SSE = 上海证券交易所
- SZSE = 深圳证券交易所

### 更新机制

股票数据的实时更新由 [StockApiQTimer](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/common/stock_api_qtimer.py) 驱动：

1. 定时器根据交易时段动态调整频率：

   - **交易时段**（9:30-11:30、13:00-15:00）：3 秒
   - **盘前**：10 秒
   - **盘后**：30 秒
2. `StockApi.wait_update()` 通过 MooTDX 批量获取实时行情
3. 数据更新后通过相同的 `ChartUpdateManager` 同步到图表

### 交易时段判断

股票的 [is_trading_time()](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/common/stock_api.py#L437) 方法判断当前是否在 A 股交易时段：

- 上午：9:30 - 11:30
- 下午：13:00 - 15:00
- 周末自动返回 False
- 非交易时段不发送数据请求，减少服务器压力

### K 线数据时间处理

股票 K 线数据来自 MooTDX 的 TCP 连接：

- 时间是 **北京时间**，**不需要时区调整**
- K 线数据格式与期货一致：`[datetime, open, high, low, close, volume]`
- 时间转换为纳秒格式（18 位），兼容 TqApi 的数据格式

## 7.3 期货与股票对比

| 特性       | 期货（TqApi）     | 股票（MooTDX）       |
| ---------- | ----------------- | -------------------- |
| 数据源协议 | WebSocket         | TCP                  |
| 连接方式   | 主动登录          | 自动连接             |
| 时间格式   | UTC（需 +8 小时） | 北京时间（无需调整） |
| 更新频率   | ~50ms（固定）     | 3s/10s/30s（动态）   |
| 交易时间   | 24 小时（含夜盘） | 9:30-15:00（仅白天） |
| 集合竞价   | 包含              | 不包含               |
| 周末处理   | 有数据            | 不更新               |
| 合约格式   | SHFE.cu2409       | SSE.600897           |
| 周末跳过   | 否                | 是                   |

## 7.4 注意事项

### 通用注意事项

- 期货和股票使用相同的 [ChartUpdateManager](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view/main_window.py#L256) 和 [ChartUpdater](https://github.com/MiniBtMaster/miniqt/blob/main/miniqt/app/view) 进行图表更新
- K 线图表通过 `is_stock` 参数区分股票和期货模式
- 切换数据源不需要重启应用，只需登录对应账户即可
- 登录后合约信息自动同步到 DuckDB 数据库，支持离线查看

### 期货特殊注意

- 期货 K 线时间显示需要加 8 小时（UTC → 北京时间）
- 夜盘数据跨越 0 点，需要注意日期处理
- 主力合约会定期切换，需要关注合约到期时间

### 股票特殊注意

- 非交易时段股票数据不会更新（`wait_update()` 直接返回 False）
- 首次打开股票图表需要等待 MooTDX 连接初始化（通过 `_init_client()` 预连接优化）
- 股票登录时系统会自动预连接 MooTDX 服务器，避免首次加载卡顿
- 股票 K 线时间不做时区调整，直接使用北京时间
- MooTDX 连接不稳定时，可能获取不了股票数据，建议检查网络连接或稍后重试
